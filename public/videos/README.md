# Exercise Video Uploads Folder

Drop `.mp4` (or `.webm`) clips into this folder named after the exercise slug.
When you run `npm run dev` or deploy on Vercel (`npm run build`), the app automatically switches from the animated illustration to your uploaded video!

Or paste YouTube / YouTube Shorts URLs instead inside `src/lib/exerciseMedia.ts`.

Priority order (most recommended to upload first):
1. `supported-chair-squats.mp4`
2. `gentle-glute-bridges.mp4`
3. `wall-push-ups.mp4`
4. `march-in-place.mp4`
5. `shoulder-rolls-chest-opener.mp4`
6. `child-s-pose.mp4`
7. `deep-breathing-inhale-4s-exhale-6s.mp4`
8. `pelvic-floor-squeeze-kegels-breath.mp4`
9. `heel-slides-lying-down.mp4`
10. `gentle-bird-dogs-from-all-fours.mp4`
